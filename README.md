# Дигитален Тракер — Android проект

Минимално Android приложение: един бутон „Добави“, който увеличава локално запазената печалба с точно 350 евроцента веднъж на местен календарен ден.

## Поведение
- Печалбата се съхранява локално като цели евроцентове.
- Запазва се датата на последното добавяне.
- Бутонът се заключва след натискане и се отключва при настъпване на следващата местна полунощ; състоянието се проверява и при повторно отваряне.
- Не изисква интернет или специални разрешения.
- Минимална версия Android 8.0 (API 26); конфигуриран е за актуални Android версии, включително One UI 8.5.

## Получаване на APK без Android Studio (компилация в облака)
В проекта има GitHub Actions workflow, който компилира APK автоматично и го предоставя като артефакт.

1. Влезте в GitHub и създайте нов **публичен** repository, например `DigitalTracker`. Не добавяйте README, лиценз или `.gitignore` при създаването.
2. Разархивирайте ZIP файла на компютър (или използвайте GitHub уеб интерфейса, за да качите всички файлове и папки от архива). Качете съдържанието на проекта, така че папката `.github/workflows/build-apk.yml` да е в корена на repository-то. Папката `DigitalTracker` съдържа Android проекта.
3. След като качите файловете в клона `main`, отворете раздела **Actions** в repository-то. Изберете **Build Android APK** и натиснете **Run workflow**, ако автоматичното изпълнение не е стартирало.
4. Изчакайте workflow да приключи със зелена отметка. Отворете изпълнението и в секцията **Artifacts** натиснете `DigitalTracker-APK`.
5. На телефона изтеглете ZIP артефакта, разархивирайте го и отворете `app-debug.apk`. Разрешете инсталиране от този източник, ако Android поиска.

**Бележка:** GitHub Actions е външна услуга и изисква GitHub акаунт. APK-ът е debug build за лично инсталиране, не е публикуван в Play Store. Изпълнението на workflow не е проверено в тази среда.

## Компилация локално
Отворете папката `DigitalTracker` в Android Studio (с Android SDK Platform 36 и JDK 17 или по-нова версия), изчакайте Gradle Sync и изберете **Build → Build Bundle(s) / APK(s) → Build APK(s)**. APK файлът ще се появи в `app/build/outputs/apk/debug/app-debug.apk`.
